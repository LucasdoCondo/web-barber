# Barbearia Imperial

Site para barbearia feito com React, TypeScript e Vite. A experiência apresenta os serviços, uma galeria horizontal e um fluxo de agendamento por modal.

## Requisitos

- Node.js
- npm

## Instalação e desenvolvimento

```bash
npm install
npm run dev
```

Abra o endereço local exibido pelo Vite no terminal.

## Build

```bash
npm run build
npm run preview
```

A build de produção é gerada pelo Vite depois da verificação de tipos TypeScript. `npm run preview` permite conferi-la localmente.
